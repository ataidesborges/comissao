    Conectar API Shopee Afiliados

    Sincronização segura via OAuth + API oficial V2

    Credenciais do afiliado: informe os dados fornecidos pela Shopee. Eles serão enviados somente ao backend por HTTPS e não serão salvos no navegador.

    Use a URL base oficial da região da sua conta de afiliado.

    Cole uma resposta JSON da API oficial V2 `get_conversion_report` para processar diretamente.

    Conexão segura com o backend da API oficial Shopee

    As credenciais e assinaturas ficam no backend. O navegador nunca recebe o App Secret, evitando exposição de credenciais e problemas de CORS.
